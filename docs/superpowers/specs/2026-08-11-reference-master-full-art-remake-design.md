# 《夜市烤冷面》参考母版全量美术重制设计

日期：2026-08-11  
状态：用户已确认，直接进入制作  
参考母版：`codex-clipboard-19b75918-d10b-475f-91ea-e6bce55262f4.png`

## 1. 目标

以用户提供的 16:9 游戏主界面为唯一视觉母版，重制项目中所有可见美术，不再沿用旧素材做局部拼补。现有经营玩法、逐日关卡、菜谱、三位并发顾客、双铁板、手势操作、第一天教程和第五天明星事件保持不变；所有场景、角色、食物、制作阶段、UI 与事件视觉统一换新。

当前完整替换基线为 `src/assets/approved/` 下 251 个文件，并包括由 CSS 绘制的 HUD、教程提示、耐心条、火候提示、订单气泡和反馈层。派生图集、缩略图与合成主画面也必须由新母版重新导出，不得继续引用旧像素。

## 2. 生产方案

评估过三种方式：

1. **资产族母版 + 确定性派生导出（采用）**：先锁定场景、人物、食物、制作阶段和 UI 五套母版，再从批准的母版导出全部运行文件。优点是一致性强、返工可局部隔离、运行时替换稳定；代价是前期规范更严格。
2. **按页面逐屏重画**：单张画面容易快速好看，但拆回互动游戏后，人物尺寸、食物视角和部件边缘难以连续。
3. **逐文件独立生成**：单项自由度最高，但 251 个文件极易出现重复脸、头身比漂移、食物角度变化和材质断层。

所有原生生成都围绕固定母版进行；相同对象的状态变化使用同一角色或菜品基准，不从零重新解释。图集、联系表、菜单合成图和缩略图使用确定性脚本组装。

## 3. 统一视觉语言

### 3.1 总体风格

- 精致商业休闲游戏美术，轻二次元人物与柔和 2.5D 场景结合。
- 正常成年头身比，五官清楚精致但不幼态、不大头、不塑料、不伪真人。
- 深蓝夜空与暖橙摊灯形成冷暖对比；前景金属台面、食材和食物获得更强局部光。
- 画面细节丰富但操作区清楚，主要交互对象拥有清晰轮廓和稳定色块。
- 质感来源于光照、体积、材质与层次，不使用纸张、水彩、铅笔颗粒或仿旧滤镜。

### 3.2 色彩与材质

- 背景：深海军蓝、暗砖红、摊棚墨绿、钨丝灯暖黄。
- UI：胡桃木棕、奶油珐琅白、墨绿、焦糖金，少量红色只用于警告与重点。
- 台面：深色拉丝金属与克制油渍高光；铁板为偏黑金属，不做夸张巨大化。
- 食物：真实可口的酱汁油润、蛋面焦香和配料纤维，不做塑料公仔材质。
- 人物：柔和皮肤明暗、清楚眼神光和夜市暖色轮廓光，不使用照片磨皮或蜡像高光。

### 3.3 构图与透视

- 16:9 横屏为主构图，场景消失点位于夜市道路中央。
- 档口为中国城市夜市场景，不出现固定座椅、欧美餐车结构或无关永久路人。
- 背景保持干净；每次最多三位当前顾客出现在档口前，并分别占据左、中、右透视站位。
- 人物脚点或腰部遮挡线固定，进入、等待和离开过程中不得整个人上下漂浮。
- 双铁板保持参考图比例，横向并列置于下半屏；食材直接摆在桌面容器内，不增设文字物品栏。

## 4. 资产系统

### 4.1 场景与主界面

重制：

- 干净夜市背景；
- 完整主界面展示图；
- 前景金属操作台、双铁板、右侧出餐区域和桌面容器；
- 灯光、蒸汽、油花和摊位环境装饰所需视觉层。

背景中不绘制会与运行顾客冲突的人物。二维码、菜单文字和摊牌只作为不可读环境细节，不生成错误品牌或乱码大字。

### 4.2 顾客与明星

保留现有 10 位顾客的身份、年龄、职业、气质和标志性穿搭，全部按新母版重画：小林同学、阿杰、晓雨、社团学长、苏晴、大壮、许研、阿哲、陈老师、王奶奶。

每位普通顾客需要：

- 稳定角色基准立绘；
- `arriving`、`ordering`、`waiting`、`impatient`、`urgent`、`happy`、`disappointed` 七种情绪；
- 进入、行走、转身、离开所需动作图集；
- 同一发型、脸型、服装、身材和光源，不随状态换脸或换衣。

第五天男明星保留“所有人都会觉得很帅、温和有礼貌”的设定，但改为与参考图相容的高精度轻二次元电影男主质感，不再使用与其他角色断裂的伪真人 3D。要求正常小头长身比例、清晰大双眼皮与克制眼部阴影、年轻平整皮肤、原创亚洲男性面孔；不得复刻现实艺人。

### 4.3 菜品与桌面食材

重制 5 款成品菜、18 个现有食材文件和外卖袋。所有对象采用统一三分之四俯视角、左上暖光和右下接触阴影。

- 成品菜必须一眼区分经典、大胃王、奥尔良鸡排、里脊火鸡和招牌芝士火鸡。
- 食材保持真实容器或自然摆放形态，缩小后仍可无文字辨认。
- 面皮、鸡蛋、热狗、火鸡面、芝士、玉米、鸡排、里脊、培根、金针菇、香菜、洋葱、辣椒粉、酱汁和葱花必须与制作阶段中的对应物一致。
- 透明素材保留克制接触阴影，四周安全边距统一，不带色键毛边、文字、水印或多余餐具。

### 4.4 制作阶段与火候

重制 5 套菜谱的所有累积阶段，而不是在同一底图上临时叠图蒙混：

- 空铁板；
- 面皮；
- 加蛋；
- 加热狗、第二张面皮、第二颗蛋、鸡排、火鸡面、芝士、玉米或里脊等各菜谱分支；
- 刷酱；
- 撒葱；
- 切段；
- 卷起；
- 装袋。

每个阶段须从前一阶段自然累积，食材相对位置、面皮形变、酱汁覆盖和熟度连续。44 个火候文件覆盖生、正好、过火、焦糊；16 个特殊要求文件覆盖加料与不加葱。火候差异通过边缘颜色、蛋液凝固、油光和焦斑表现，不依赖文字。

### 4.5 UI 与教程

所有运行时可见 UI 统一为参考图体系：

- 左上悬挂式天数木牌；
- 满意度笑脸奖牌；
- 顶部居中的金币木牌；
- 右上订单目标牌与圆形暂停按钮；
- 顾客头顶紧凑奶油色订单气泡；
- 绿色耐心条、金色制作进度、火候环与反馈提示；
- 第一天教程木牌、刷酱方向提示、拖动轨迹和完成提示；
- 日结、关卡选择、升级、帮助与第五天剧情弹层。

UI 图标采用统一圆润雕刻感；中文由代码或矢量排版产生，不让图像模型生成关键文字。订单气泡不得遮挡人物脸部，尾部指向对应顾客；三个气泡同时出现时仍保持间距。

### 4.6 第五天事件

重制明星事件主视觉及运行角色素材。事件画面延续相同夜市场景和灯光，明星礼貌排队、点单与接餐；普通顾客以视线和轻微姿态反应表达“确实很帅”，不围堵、不遮挡操作区。事件 UI 与主界面使用同一木牌和奶油珐琅组件。

## 5. 文件与派生规则

- 保持当前运行时路径和稳定文件名，降低接入风险。
- 角色基础图、旧 `final-light-anime` 文件和情绪图改为从同一角色母版导出，禁止多套相互矛盾的人脸。
- 动作 atlas 从通过检查的独立帧确定性组装；未使用单元保持透明。
- 五个菜谱 atlas 从对应阶段图确定性组装，不单独重新生成。
- 菜单 PNG 由可编辑 SVG 与最终成品菜图确定性导出，关键中文和价格保持准确。
- 新生成源文件与最终运行资产分目录保存；项目只引用最终优化后的 PNG/SVG。
- 旧资产在新资产全部通过验证前不删除；切换采用原子替换，避免半套新旧混用。

## 6. 运行时接入

保持现有 `campaign`、`assets`、顾客时间线、烹饪 reducer 和关卡逻辑。允许修改组件结构与 CSS 以实现参考图布局，但不改变玩法规则。

接入顺序：

1. 场景和 UI 框架；
2. 桌面食材与双铁板；
3. 全部制作阶段和火候；
4. 顾客静态情绪；
5. 顾客动作图集；
6. 第五天事件；
7. 关卡、日结和教程等剩余界面；
8. 清理不再使用的旧视觉入口。

每个资产族接入后先完成自动契约检查，但不要求用户逐张确认。只有发生无法从参考图推断、且会改变已确认设定的重大冲突时才暂停询问。

## 7. 质量与验收

### 7.1 自动检查

- 251 个目标文件存在、非空、路径正确；
- PNG 尺寸、色彩模式、Alpha 通道和安全边距符合各资产契约；
- 图集行列、帧尺寸、基线和透明单元正确；
- 所有菜谱阶段、火候和 modifiers 可由运行时解析；
- 中文文案和价格不由位图生成，关键文本无乱码；
- 类型检查、全部测试和生产构建通过。

### 7.2 视觉检查

- 全项目只有一套可识别的视觉语言，无旧纸纹、旧 Q 版、伪真人或扁平默认 UI 混入；
- 11 位人物身份稳定、脸不重复、头身比正常、情绪和动作连续；
- 三名顾客透视站位、脚点和气泡不冲突；
- 食材缩略后可辨认，成品菜与制作过程内容一致；
- 双铁板可同时工作，阶段画面不互相串位；
- 1440×810、1280×720、1024×576 和 844×390 均无关键遮挡；
- 第一日完整教程、第三日火鸡面、第五日明星事件和第六日高压订单均可完整体验。

最终提供按类别组织的资产文件夹、全套联系表、视觉验收截图和可完整体验的游戏链接。用户不参与中间逐张审核，只查看最终整套结果。
